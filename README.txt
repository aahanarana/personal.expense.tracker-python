PERSONAL EXPENSE TRACKER

Files:
- personal_expense_tracker.py : Python program
- expenses.csv                : Your supplied expense entries
- expense_report.xlsx         : Excel report with transactions and category totals
- requirements.txt            : Package needed for Excel export

Run:
1. Install Python 3.
2. Open this folder in VS Code.
3. In the VS Code terminal, run:
   python3 -m pip install -r requirements.txt
4. Run:
   python3 personal_expense_tracker.py

The CSV contains only the transactions you provided. No Bills transactions
were added because no Bills entries were supplied. Dates were selected in
November 2026 for the sample records.
